## Interface and evaluation

From `services/selar-worker`:

```sh
python -m offline_evidence --gold /path/to/frozen.json --sha256 EXPECTED_SHA256 \
  --predictions /path/to/predictions.json --split development
```

`predictions.json` is a JSON array containing exactly one object per pair in the requested split; each has `pair_id` and `label`. `label` may be `none`, `abstain`, or a predicted relationship class. For every predicted relationship, include both `query_evidence` and `candidate_evidence`, each `{"chunk_id":"...","quote":"exact contiguous substring of frozen chunk text"}`. No predictions are generated by this evaluator. A missing side fails closed; unknown chunk, wrong-side chunk, empty or non-verbatim quote is counted unsupported. Prediction-side evidence is checked against immutable document/chunk identity, locator, text hash; it is **not** assumed valid because a gold chunk ID exists. No reference to gold's supporting chunk IDs is required to count a prediction's textual grounding; semantic correctness requires separate expert review.

The caller supplies the expected SHA-256 and precomputed predictions. Freeze model, code, thresholds, and predictions **before** held-out scoring. The evaluator neither trains nor chooses a threshold, and derives a split's class report only from that split plus submitted predictions; no development report exposes held-out-only labels. It rejects duplicate document/chunk/pair IDs, duplicate directed pairs, document overlap across splits, invalid support ownership, missing rubric/reviewer or authorization fields, digest changes, and missing/duplicate/extra predictions. It does not modify source bytes.

Per-class `tp/fp/fn/support/precision/recall/f1` use owner-authorized labels and all selected gold rows; abstentions count as FN for the true class but not FP for another class. Zero-denominator precision/recall/F1 are `0.0` (with counts retained). Coverage = decided / evaluated pairs; unsupported-link rate = unsupported predicted positive links / all predicted positive links, including wrong-label positives; `null` when no positive links predicted. Class metrics measure **label match**, not evidence adequacy; unsupported-link rate is separate. No real model predictions have been supplied; no model performance number is claimed.
