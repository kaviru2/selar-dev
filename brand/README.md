# SELAR brand kit

Identity and marketing assets for SELAR (Semantic Linking for Active Retention), a **research prototype** from UCSC IS4101 Group 04.

Principle: **AI suggests, sources show, you explain and decide.**

| Path | What |
| --- | --- |
| `DESIGN.md` | Design tokens + rules (Google DESIGN.md spec, lint: 0 errors / 0 warnings). `tokens.dtcg.json` and `theme.css` are exports. |
| `guide/SELAR-brand-guide.pdf` | Visual brand guide (logo usage, clear space, colour + contrast, type, mascot, voice, claim rules). |
| `exports/logo/` | Recommended direction **A: Linny** (a linnet holding a page). Lockup, descriptor lockup, stacked, icon, wordmark; colour, on-dark, mono ink, mono white; SVG + PNG. |
| `exports/favicon/` | `favicon.ico` (16/32/48), PNG 16/32/48, apple-touch-icon 180, 192/512, maskable 512, `favicon.svg`, `site.webmanifest`. |
| `exports/mascot/` | Linny in 7 poses: hello, reading, linking, thinking, celebrating, questioning, empty. |
| `exports/exploration/` | All three explored directions (A Linny, B Page Bridge, C Knot S) + `brand-exploration-comparison.png`. |
| `marketing/` | OG card, 3-slide carousel (1080x1350), 2 squares (1080x1080), A4 flyer (PDF/PNG), taglines + pitch + draft captions. Nothing has been posted. |
| `tools/` | Python sources that draw everything (SVG primitives, fonts outlined via fontTools, rendered with resvg / headless Chrome). |

Console integration lives in `services/selar-console`: `components/brand/` (`Logo`, `LogoMark`, `Wordmark`, `Linny`), `app/favicon.ico`, `app/icon.svg`, `app/apple-icon.png`, `app/opengraph-image.png`, `app/twitter-image.png`, `app/manifest.ts`, and metadata in `app/layout.tsx`. `components/brand/*.tsx` is generated by `tools/gen_tsx.py`.

## Claims (hard rules)

- Always say "research prototype". Never claim SELAR improves memory, retention, grades or learning; the retention study is planned, not run.
- Survey only as reported: 38 eligible respondents; 31/36 wanted linking; 28/36 worried about AI accuracy; 24/36 worried about less active thinking.
- No testimonials, user counts, partner logos, prices or incentives.

## Rebuild

```bash
pip install pillow fonttools resvg-py segno pymupdf
# put Fraunces[SOFT,WONK,opsz,wght].ttf, Figtree[wght].ttf, JetBrainsMono[wght].ttf in brand/fonts/
cd brand/tools
python build_identity.py && python build_marketing.py comparison og flyer carousel squares && python build_guide.py && python gen_copy.py
python gen_tsx.py ../../services/selar-console
```
Output goes to `brand/build-out/` (override with `SELAR_BRAND_ROOT`).
