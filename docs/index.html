Semantic Linking for Active Retention

A reader for papers and notes that suggests grounded connections between your readings, then prompts you to recall, compare and explain them.

View on GitHub Get started

Research prototype, not a proven learning intervention. SELAR is the instrument for a UCSC final-year research study. AI suggestions can be wrong, and no claims are made about memory, retention or grades.

The learning loop

Each document becomes one flow: warm up, read and compare, check, then review later.

📚

Library

PDF, Markdown, TXT and DOCX snapshots, public web articles, pasted text, and optional Google Drive import.

💭

Before-reading warm-up

Optional recall questions generated from your own document, each tied to a source passage.

🔗

Reflection prompts

Grounded concept links between readings. Compare the two passages side by side, or flag one tap: “This link is wrong”. No keep/reject step.

✅

End-reading check

A short check after reading, with AI support checking and feedback on free recall answers.

📅

Daily review

A conservative spaced review schedule, daily session and UTC streak. Progress shows observed attempts, not mastery.

💬

Chat and graph

Library-grounded questions with citations to check, and a concept graph of how your readings connect.

Architecture

Next.js console → Go API → PostgreSQL/pgvector, with a Python worker calling Google Gemini for document processing, chat and practice.

Deployment

Hosted infrastructure and production configuration for operators.

Document processing, chat and practice use Gemini: content you upload may be sent to the model provider and can use quota or incur charges, even when SELAR runs locally.
