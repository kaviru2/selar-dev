Core Features

SELAR turns passive PDF reading into active knowledge construction. Built for researchers, designed for retention.

🔍

Semantic Link Discovery

Automatic vector embedding of document chunks via Gemini. Bi-directional cross-document link suggestions using cosine similarity with pgvector.

🎯

Active Retrieval Practice

Confirm, reject, or relabel every suggestion. Each interaction is a micro-test calibrated against spaced repetition principles.

🕸

Knowledge Graph

Automatic concept extraction and force-directed visualization. Explore how your papers connect at the idea level, not just the citation level.

📄

PDF Reader

Continuous-scroll rendering with manual highlighting, annotations, and a floating popup menu for notes. Matches panel alongside your reading.

🤖

AI Relation Classification

Every link is classified: prerequisite_of, extends, sub_concept_of, contradicts, or related_to. With human-readable summaries.

📚

Document Library

Upload, track processing status, view stats. Cascading cleanup on delete. Real-time progress indicators during ingestion.

Quick Start

Get SELAR running locally in under 5 minutes.

# Clone and configure
git clone https://github.com/Kavirubc/selar-dev.git
cd selar-dev
cp .env.example .env.development
# Edit .env.development and set GEMINI_API_KEY

# Set up database
createdb selar
psql -d selar -c "CREATE EXTENSION IF NOT EXISTS vector;"
psql -d selar -c "CREATE EXTENSION IF NOT EXISTS pgcrypto;"
psql -d selar -f services/selar-api/internal/store/migrations/001_init.sql
psql -d selar -f services/selar-api/internal/store/migrations/002_add_summary.sql

# Terminal 1 — Go API
cd services/selar-api && go run cmd/server/main.go

# Terminal 2 — Python Worker
cd services/selar-worker && pip install -r requirements.txt
python3 -m uvicorn main:app --reload --port 8000

# Terminal 3 — Next.js Console
cd services/selar-console && pnpm install && pnpm dev

# Open http://localhost:3000
